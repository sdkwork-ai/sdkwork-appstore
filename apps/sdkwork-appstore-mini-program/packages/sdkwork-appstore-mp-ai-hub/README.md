# @sdkwork/appstore-mp-ai-hub

Ai Hub capability package for the SDKWork App Store mini program.

Owns route identities: `app.store.ai-hub.index` (`/ai-hub`), `app.store.ai-hub.experts` (`/experts`), `app.store.ai-hub.skills` (`/skills`), `app.store.ai-hub.mcp` (`/mcp`).

Receives the generated app SDK client by injection; never constructs one.
