# sdkwork_appstore_flutter_mobile_ai_hub

Ai Hub capability package for the SDKWork App Store Flutter
mobile root.

Owns route identities: `app.store.ai-hub.index` (`/ai-hub`), `app.store.ai-hub.experts` (`/experts`), `app.store.ai-hub.plugins` (`/plugins`), `app.store.ai-hub.skills` (`/skills`), `app.store.ai-hub.mcp` (`/mcp`), `app.store.ai-hub.templates` (`/templates`), `app.store.ai-hub.template-detail` (`/template/:id`), `app.store.ai-hub.template-detail-alias` (`/templates/:id`).

Receives the App Store app SDK clients by injection; never constructs a client.
